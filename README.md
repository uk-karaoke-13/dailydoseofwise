# daily.dose.of.wise — reel hosting

Public hosting for the quote reels of the Instagram page **daily.dose.of.wise** and its YouTube Shorts channel.
Metricool fetches each reel from its raw link when scheduling posts.

- `reels/` — rendered reels (1080×1920, MP4), one per quote.

Reels are generated weekly; the working files and tracking spreadsheet live outside this repository.
